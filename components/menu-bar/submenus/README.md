# Menu Bar Submenus

This directory contains the individual submenu components for the menu bar:

- `gemini-settings.js` - Gemini API configuration submenu
- `voice-settings.js` - Voice/ElevenLabs API configuration submenu  
- `color-settings.js` - Color theme and customization submenu
- `about-section.js` - About section content submenu

These files were moved from the parent directory to improve component organization.
